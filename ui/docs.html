PureCVisor Single Edge
기술 문서

단일 노드 설치부터 VM·컨테이너 운영, ZFS·네트워크, 보안, REST API와 출시 검증까지 필요한 작업에서 바로 시작하세요.

빠른 시작

서비스 기동부터 첫 VM과 Web UI 접속까지 확인합니다.
워크로드

VM과 컨테이너의 생성, 수명주기, 복제와 자원 제어를 다룹니다.
인프라

ZFS, 네트워크, 모니터링과 백업 운영 절차를 연결합니다.
개발·출시

소스 구조, 불변 규칙과 릴리스 전 품질 게이트를 확인합니다.
GUIDE CATEGORIES

필요한 작업에서 시작하세요.

21개 장을 8개 작업 카테고리로 묶고 모든 문서의 제목과 내용을 펼쳐 두었습니다. 각 항목은 기존 전체 가이드의 정확한 장으로 연결됩니다.

CATEGORY 01 · GET STARTED

시작·설치

제품의 역할을 이해하고 요구사항 확인부터 서비스 기동과 운영 배포까지 완료합니다.

CHAPTER 01

시작하기

제품 개요, 아키텍처, 5분 퀵스타트와 접속·수동 RPC 확인 절차를 안내합니다.

 CHAPTER 02

설치 및 환경 구성

Ubuntu 26.04 권장 구성, 패키지·빌드, systemd, daemon.conf와 로컬 Single Edge 배포를 설명합니다.
CATEGORY 02 · WORKLOADS

VM·컨테이너

가상 머신과 컨테이너의 생성부터 수명주기, 복제, 자원 제어까지 운영합니다.

CHAPTER 03

VM 관리

VM 생성, 수명주기, 핫플러그, 스냅샷·복제·OVA와 템플릿을 다룹니다.

 CHAPTER 04

컨테이너 관리

생성·명령 실행, cgroup 제한, 복제, 체크포인트, Seccomp와 NIC를 설명합니다.
CATEGORY 03 · INFRASTRUCTURE

스토리지·네트워크

데이터 저장 계층과 단일 노드 네트워크를 구성하고 공개 범위의 경계를 확인합니다.

CHAPTER 05

스토리지

ZFS pool·zvol, iSCSI, 스토리지 티어링, ISO와 메트릭을 관리합니다.

 CHAPTER 06

네트워크

bridge, nftables, QoS, VXLAN·OVN, DPDK·SR-IOV와 Local VPC를 다룹니다.
CATEGORY 04 · OBSERVE & RECOVER

모니터링·복구

노드와 워크로드 상태를 관측하고 경보, 백업과 검증된 복원 절차로 연결합니다.

CHAPTER 08

모니터링 & 알림

메트릭, 프로세스 감시, 경보·웹훅, SLA, tracing과 Web Push를 설명합니다.

 CHAPTER 09

백업 & 복원

정책 기반 백업, 무결성 검증, 비동기 실행, 보존과 복원 절차를 다룹니다.
CATEGORY 05 · SECURITY & AUTOMATION

보안·마이그레이션

접근 제어와 호스트 방어를 적용하고 클라우드 이동·자가치유의 안전 경계를 확인합니다.

CHAPTER 10

보안

인증·RBAC, API Key, JWT·CSRF, HIDS/HIPS, 감사와 IPS를 설명합니다.

 CHAPTER 11

클라우드 마이그레이션

AWS EC2 가져오기·내보내기, 작업 추적과 안전한 취소 흐름을 안내합니다.

 CHAPTER 12

AI & 자가치유

이상 탐지, 다중 제공자 합의, 승인 큐와 자가치유 안전장치를 다룹니다.
CATEGORY 06 · INTERFACES

Web UI·API·CLI

운영자가 사용하는 브라우저 콘솔과 자동화를 위한 REST·CLI 인터페이스를 연결합니다.

CHAPTER 13

Web UI

화면 구조, 테마, i18n, PWA, 실시간 이벤트, 반응형과 접근성을 설명합니다.

 CHAPTER 14

REST API

API 기본 계약, endpoint별 rate limit·timeout과 주요 경로를 확인합니다.

 CHAPTER 15

CLI 레퍼런스

pcvctl의 명령 분류, 출력 형식과 자동완성 설치 방법을 안내합니다.
CATEGORY 07 · CONFIGURE & TROUBLESHOOT

설정·문제 해결

설정 정본과 장애 대응 명령을 빠르게 찾고 운영에 필요한 참조 정보를 확인합니다.

CHAPTER 16

설정 레퍼런스

daemon.conf의 위치와 전체 설정 키·기본값·운영 의미를 확인합니다.

 CHAPTER 17

트러블슈팅

자주 발생하는 증상별 원인·조치, 디버그 명령과 로그 위치를 제공합니다.

 CHAPTER 18

부록

용어, 오류 코드, 외부 의존성, 포트와 파일 경로를 한곳에 모았습니다.
CATEGORY 08 · BUILD & RELEASE

개발·출시

제품을 설명하고 수정하는 기준부터 구조 개선과 릴리스 품질 판정까지 연결합니다.

CHAPTER 19

개발자 & 엔지니어 가이드

개발 불변 규칙, 변경 흐름, 최소 검증과 운영 handoff 기준을 설명합니다.

 CHAPTER 20

영업 & 마케팅 가이드

포지셔닝, 적합 고객, 데모 흐름, 반론 대응과 메시지 경계를 정리합니다.

 CHAPTER 21

아키텍처 리팩토링 가이드

REST middleware, CLI 통신·출력, dispatcher와 hook 구조를 안내합니다.

 CHAPTER 22

품질 게이트 가이드

변경 수준별 빌드·테스트·보안·UI 검증과 출시 판정 기준을 제공합니다.
RECOMMENDED PATHS

역할에 맞는 순서로 읽으세요.

한 장씩 모두 읽지 않아도 됩니다. 현재 해야 할 일에 맞는 출발점과 다음 확인 항목을 연결했습니다.

01 · FIRST RUN

처음 설치하는 운영자

5분 퀵스타트에서 서비스·인증·첫 VM을 확인한 뒤 설치·환경 구성으로 확장합니다.

 02 · OPERATE

현재 노드를 운영하는 엔지니어

모니터링과 알림에서 상태를 확인하고 트러블슈팅·백업 복원으로 이어갑니다.

 03 · BUILD & RELEASE

제품을 수정하는 개발자

소스 불변 규칙과 ADR을 먼저 읽고 품질 게이트에서 변경 수준에 맞는 검증을 고릅니다.
