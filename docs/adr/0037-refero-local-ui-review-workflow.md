# ADR-0037: 외부 UI 연구 workflow는 공개 런타임 계약과 분리한다

날짜: 2026-08-11  
상태: Historical  
Single Edge 적용 상태: 공개 제품 런타임에 영향 없음

## 맥락

제품 UI 연구 과정에서는 Refero 같은 외부 레퍼런스 서비스와 로컬 화면 검토를 사용했다.
외부 서비스의 연결·구독·할당량 상태가 제품 코드 검증이나 backend·CLI·infra 작업을 막으면
안 되며, 외부 보고서만으로 UI 완료를 선언해서도 안 된다.

## 결정

공개 저장소의 UI 시각 계약은 `DESIGN.md`가 소유한다. 구현 검증은 제품 테스트,
`scripts/check_design_md.py`, `tests/integration/test_design_md_surface.sh`와 브라우저 검증으로
수행한다. 외부 UI 연구 도구와 비공개 검토 보고서는 공개 릴리스의 필수 의존성이 아니다.

## 결과

- 공개 저장소는 외부 서비스 인증정보와 비공개 연구 기록을 포함하지 않는다.
- UI 변경은 저장소 내부 계약과 재현 가능한 테스트로 검증할 수 있다.
- 외부 레퍼런스는 참고 근거이며 제품 테스트를 대체하지 않는다.
