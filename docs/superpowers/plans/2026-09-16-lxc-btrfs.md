# 선택형 LXC Btrfs 구현 계획

> 실행 스킬: `superpowers:subagent-driven-development`. 구현과 명세 검토, 코드 품질 검토를 분리한다.

**목표:** 명시 선택한 Btrfs 저장소에서 PureCVisor 컨테이너의 안전한 생성·복제·snapshot·복원·삭제를 지원한다.

**구조:** 저장소 identity와 Btrfs 조작은 `lxc_storage.c/.h`가 소유한다. 기존 driver가 작업 lock, 정지 조건, native LXC와 연결하고 handler가 owner/audit 결과를 보존한다.

**기술:** C23, GLib/GTask, liblxc, Btrfs ioctl/argv, Linux renameat2, Python 회귀, 실제 Arch API 검증.

## 엔지니어링 사전 검토

- 설계의 경로/소유권 검사는 명령 실행 전 수행한다. 단순 문자열 prefix 대신 component와 실제 파일 종류/identity를 사용한다.
- 원자 교환과 journal 각각의 실패를 검증한다. journal을 지워서 성공처럼 보이게 하지 않는다.
- driver와 storage 모듈의 파일 소유권을 나눠 편집 충돌을 방지한다.
- 기존 공개 브랜치에서 분리한 worktree를 사용한다. 비공개 저장소의 미완료 수정은 포함하지 않는다.
