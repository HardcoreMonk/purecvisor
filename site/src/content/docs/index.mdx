  <section class="pcv-scene pcv-intro" id="capabilities" aria-labelledby="pcv-intro-title">
    <div class="pcv-shell">
      <div class="pcv-section-heading pcv-section-heading-wide">
        <p class="pcv-kicker">WHAT PURECVISOR DOES</p>
        <h2 id="pcv-intro-title">한 노드의 가상화 운영을<br />하나의 흐름으로.</h2>
        <p>PureCVisor Single Edge는 독립 노드의 워크로드와 기반 인프라를 같은 제어면에서 연결합니다. 요청은 권한 정책을 거쳐 실행되고, 장시간 작업은 결과 채널과 audit으로 완료 상태를 남깁니다.</p>
      </div>

      <div class="pcv-capability-grid">
        <article class="pcv-capability pcv-capability-wide">
          <span class="pcv-feature-index">01 · COMPUTE</span>
          <h3>VM과 컨테이너 수명주기</h3>
          <p>KVM VM과 LXC 컨테이너를 생성하고 시작·중지하며, 템플릿과 안전장치를 갖춘 VM 복제 흐름을 운영합니다.</p>
          <a href="/ko/workloads/virtual-machines/">워크로드 가이드 <span aria-hidden="true">→</span></a>
        </article>
        <article class="pcv-capability">
          <span class="pcv-feature-index">02 · STORAGE</span>
          <h3>데이터 위치와 복구</h3>
          <p>ZFS pool·zvol, qcow2/raw와 iSCSI를 관리하고 백업·복원 절차로 이어갑니다.</p>
          <a href="/ko/infrastructure/storage/">스토리지 가이드 <span aria-hidden="true">→</span></a>
        </article>
        <article class="pcv-capability">
          <span class="pcv-feature-index">03 · NETWORK</span>
          <h3>로컬 SDN</h3>
          <p>Linux bridge, OVS와 OVN Local VPC를 독립 노드 네트워크 경계 안에서 구성합니다.</p>
          <a href="/ko/infrastructure/networking/">네트워크 가이드 <span aria-hidden="true">→</span></a>
        </article>
        <article class="pcv-capability">
          <span class="pcv-feature-index">04 · OBSERVE</span>
          <h3>관측과 작업 결과</h3>
          <p>호스트 메트릭, 알림, job completion과 audit 기록으로 accepted 이후의 실제 결과까지 확인합니다.</p>
          <a href="/ko/operations/monitoring-alerts/">모니터링 가이드 <span aria-hidden="true">→</span></a>
        </article>
        <article class="pcv-capability">
          <span class="pcv-feature-index">05 · INTERFACES</span>
          <h3>세 가지 운영 인터페이스</h3>
          <p>Web UI, REST API와 pcvctl CLI가 같은 Single Edge 기능과 권한 계약을 공유합니다.</p>
          <a href="/ko/interfaces/web-ui/">인터페이스 가이드 <span aria-hidden="true">→</span></a>
        </article>
        <article class="pcv-capability pcv-capability-dark">
